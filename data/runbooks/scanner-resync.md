# Handheld scanners not syncing picks

Owner: Warehouse systems. Class: LOL Internal. Last reviewed: 2026-05-28.

1. Check Wi-Fi first. If several scanners in one area drop at once, it's the access points, not the scanners. Raise to network with the aisle numbers.
2. For a single scanner: hold power 10 seconds, wait for the green light, log in again. Picks in the queue resend on reconnect.
3. If a scanner shows yesterday's pick list, the overnight sync failed. Don't let pickers work from it. Force a sync from the dock terminal: Admin → Devices → Resync.
4. Stock showing in the wrong aisles after a sync means the location master was loaded wrong. Stop picking in the affected zone and call the shift lead.

Paper pick lists are the fallback. Keep a printed set at every dock.
